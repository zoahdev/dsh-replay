第一章 项目是什么

KineGrant 是一个开源的物理 AI 授权协议，给机器人和“具身智能”系统提供“动手之前的授权与问责层”。

要解决的问题：AI 模型会决定“我要开门”“我要录像”“我要训练”，但在模型决定和机器真正执行之间，目前没有统一、可验证、可审计的授权环节。KineGrant 补上这个环节。

核心流程（一句话）：机器人声明想做的动作 → 策略引擎按规则决策 → 签发短时、一次性、加密签名的“能力许可” → 执行器旁边的本地门禁验证并原子消费 → 执行完成后出签名收据。

官方资料：
- 官网：https://kinegrant.com
- GitHub 主仓库：https://github.com/zoahdev/kinegrant-protocol
- 默认分支：main
- 协议规范草案：KGP-001 Experimental Open Draft 0.1（正文在 spec/KGP-001.md）

KineGrant 明确不做的事（红线，不能违反）：
1. 不做代币、加密货币、区块链经济层；
2. 不宣称自己是功能安全（functional safety）系统或替代安全控制器；
3. 不做运动规划、机器人中间件；
4. 不把“签名有效”当作“物理世界真的发生了”的证据；
5. 不做单家厂商控制的云接口（协议必须开放、中立）。

KineGrant 的差异化护城河（任何新功能都不能破坏）：
1. 短时、一次性能力 + 原子消费 + 崩溃持久化防重放（SQLite replay store）；
2. 签名、哈希链收据 + 隐私最小化（收据不含原始视频/音频/个人数据）+ 调用方自持信任锚；
3. 可离线复现的 Machine Permission Test（MPT）：校验和寻址证据包，任何人可离线验证，不信任网站 UI；
4. 严格 fail-closed 适配器：看不懂的外部授权文档直接拒绝，绝不悄悄放宽；
5. 主动对齐现有标准：W3C ODRL、W3C WoT、IEEE 7012、ROS 2/SROS2、OPC UA、Matter。
